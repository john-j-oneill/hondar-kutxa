# hondar-kutxa

*Hondar-kutxa* is Basque for "sandbox", and that's what this repo is: a place
for experiments, throwaway code and one-off tests. Nothing here is maintained,
stable or meant to be depended on.

## Layout

- [`ai-oneshots/`](ai-oneshots/): small projects generated by AI coding
  assistants from a single prompt (plus maybe a few follow-up fixes).
- [`unraid/`](unraid/): Docker build scripts and container templates for
  running things on an Unraid server (currently [Strata](unraid/strata/)).
